# Reporting a security issue

Please use GitHub's **Report a vulnerability** option in this repository's
Security tab for a private report. The owners must enable private vulnerability
reporting before public release. If that option is unavailable, ask a maintainer
for a private reporting route without posting vulnerability details publicly.

Do not put credentials, personal records, private documents, or working exploit
details in public issues or pull requests. Provide affected versions, a redacted
description of the impact, and a minimal reproduction using synthetic data.

This is an academic project. No security response time or supported release
schedule is currently promised. Never test against hosted systems or other
people's accounts without the owners' explicit permission.
